## `calendars_status`

Report whether this process can read/write macOS Calendars and Reminders, which accounts exist, what the current defaults are, and exactly how to fix a missing permission. Call this first whenever another tool returns permission_denied, or before a batch of calendar work.

Takes no arguments.

## `calendars_request_access`

Ask macOS for Full Access to Calendars and Reminders by triggering the native consent dialog. Use after calendars_status reports notDetermined or denied. If macOS has already recorded a denial, the dialog will not reappear and the user must change it in System Settings.

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `calendars` | boolean | no | Request Calendars access. Defaults to true. |
| `reminders` | boolean | no | Request Reminders access. Defaults to true. |

## `calendars_open_privacy_settings`

Open System Settings directly on the Calendars or Reminders privacy pane so the user can grant Full Access. Use when a permission cannot be fixed by a prompt.

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `pane` | string | yes | Which privacy pane to open. One of: `calendars`, `reminders`. |

## `calendars_list_accounts`

List the accounts (iCloud, Google, Exchange, local, subscribed) that hold calendars and reminder lists, with the number of containers in each. Use it to know which account a new calendar or list can be created in.

Takes no arguments.

## `calendar_create_event`

Create a calendar event. Give 'start' plus either 'end' or 'duration_minutes'; with neither, the event lasts one hour. A date-only 'start' with no duration creates an all-day event, matching Calendar.app — pass a time of day to get a timed event. The target calendar must be writable.

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `alarms` | array of object | no | Reminder offsets for the item. Each entry is {"minutes_before": 15} (relative), {"at": "2026-10-10T09:00"} (absolute), or {"location": {"title": "Office", "latitude": 31.23, "longitude": 121.47, "radius": 150, "on": "enter"}} (geofence). Passing the array replaces all existing alarms; pass an empty array to remove them. |
| `all_day` | boolean | no | Create an all-day event. Inferred when 'start' is a bare date and no duration is given; pass false to force a timed event. |
| `availability` | string | no | Free/busy status. One of: `busy`, `free`, `tentative`, `unavailable`. |
| `calendar` | string | no | Calendar name, or the special values 'all' or '*'. Names are matched exactly first, then case-insensitively, then as a substring; an ambiguous match is an error rather than a guess. |
| `calendar_id` | string | no | Exact calendar identifier from calendar_list_calendars. Takes precedence over the name. |
| `confirm` | boolean | no | Must be true to actually apply a change while write mode is 'ask' (the default). Without it, mutating tools return a preview and write nothing. |
| `dry_run` | boolean | no | Preview only. Never writes, in any write mode. |
| `duration_minutes` | integer | no | Length in minutes. Rounded up to whole days for an all-day event. |
| `end` | string | no | End date-time. Defaults to start + duration_minutes, or +1 hour. For an all-day event this names the LAST day the event covers, inclusive: a one-day all-day event needs no 'end', and 'end' equal to 'start' means one day, not zero. |
| `location` | string | no | Free-text location. |
| `notes` | string | no | Free-text notes. |
| `recurrence` | array of object | no | Recurrence rule. Passing this array replaces the existing rules; pass an empty array to make the item non-recurring. |
| `start` | string | yes | Start date-time, e.g. '2026-10-10T15:00', 'tomorrow 15:00', '+2h'. |
| `timezone` | string | no | IANA time zone for interpreting and rendering dates, e.g. 'Asia/Shanghai'. Defaults to the machine's current zone. |
| `title` | string | yes | Event title. |
| `url` | string | no | URL to attach. |

## `calendar_update_event`

Change fields on an existing event. Only the fields you pass are modified. Moving 'start' without giving 'end' or 'duration_minutes' keeps the original length. A bare date here never converts a timed event to all-day — pass 'all_day' explicitly. For a recurring series, pass 'occurrence_date' to pick the occurrence and 'span' to choose how much of the series changes.

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `alarms` | array of object | no | Reminder offsets for the item. Each entry is {"minutes_before": 15} (relative), {"at": "2026-10-10T09:00"} (absolute), or {"location": {"title": "Office", "latitude": 31.23, "longitude": 121.47, "radius": 150, "on": "enter"}} (geofence). Passing the array replaces all existing alarms; pass an empty array to remove them. |
| `all_day` | boolean | no | Switch between all-day and timed. An all-day event keeps its day span unless 'end' or 'duration_minutes' is also given. |
| `availability` | string | no | Free/busy status. One of: `busy`, `free`, `tentative`, `unavailable`. |
| `clear` | array of string | no | Field names to reset to empty: notes, location, url, alarms, recurrence, timezone (events) or notes, url, location, due, start, alarms, recurrence (reminders). |
| `confirm` | boolean | no | Must be true to actually apply a change while write mode is 'ask' (the default). Without it, mutating tools return a preview and write nothing. |
| `dry_run` | boolean | no | Preview only. Never writes, in any write mode. |
| `duration_minutes` | integer | no | New length; recomputes the end from the start. Rounded up to whole days for an all-day event. |
| `end` | string | no | End date-time. Defaults to start + duration_minutes, or +1 hour. For an all-day event this names the LAST day the event covers, inclusive: a one-day all-day event needs no 'end', and 'end' equal to 'start' means one day, not zero. |
| `id` | string | yes | Exact item identifier as returned by the list tools. |
| `location` | string | no | New location. Pass an empty string to clear it. |
| `notes` | string | no | New notes. Pass an empty string to clear them. |
| `occurrence_date` | string | no | For a recurring event, the occurrenceDate value returned by calendar_list_events. Needed to target one occurrence instead of the whole series. |
| `recurrence` | array of object | no | Recurrence rule. Passing this array replaces the existing rules; pass an empty array to make the item non-recurring. |
| `span` | string | no | Which part of a recurring series the change applies to. One of: `this`, `this_and_future`, `all`. |
| `start` | string | no | New start. |
| `timezone` | string | no | IANA time zone for interpreting and rendering dates, e.g. 'Asia/Shanghai'. Defaults to the machine's current zone. |
